## ✨ Features for Your Server

* **🟢 Live Radar:** A dedicated channel post that automatically updates every 30 seconds. It displays detailed server info such as player count, ping, map, active multipliers, and BattlEye status.
* **📊 Event History:** Tracks the last 50 player join and leave events with precise timestamps.
* **🚨 Live Notifications:** Have the bot ping a specific role whenever players join or leave the server (configurable: Join & Leave, Joins Only, or Leaves Only).
* **🔄 Dynamic Channel Name:** The bot can automatically rename your Discord channel to display the current player count directly in your channel list.
* **🔑 Premium Slots:** Use redeemable keys to unlock additional server trackers for your community.

---

## 🤖 Slash Commands

Control the bot effortlessly using modern Discord Slash Commands:

| Command | Description |
| :--- | :--- |
| `/setup <server>` | Starts the interactive setup for the Live Radar in the current channel. |
| `/server <server>` | Instantly displays live info and the last 50 events of a specific server. |
| `/status` | Shows your current premium status and used server slots. |
| `/redeem <key>` | Redeems a premium key to unlock more tracker slots for your Discord. |
| `/stop` | Stops the Live Radar and ends tracking in the current channel. |

---

## 🖥️ Easy Interactive Setup

When you type `/setup`, the bot opens an intuitive user interface directly inside your Discord channel:

1. **Role Dropdown:** Optionally select a role to be pinged when player events (Join/Leave) occur.
2. **Ping Mode:** Choose whether you want to be notified for *Join & Leave*, *Joins Only*, or *Leaves Only*.
3. **Rename Channel:** Toggle the automatic channel name updates based on the live player count on or off.
